## Task 1: Check if a Number is Even or Odd

### Problem Statement
Write a Python program that:
1. Takes an integer input from the user.
2. Uses an `if-else` statement to determine whether the number is even or odd.
3. Displays the result accordingly.

### Expected Output
The program should display:
- `"The number is even."` if the input number is even  
- `"The number is odd."` if the input number is odd  

### Example
    Enter a number: 4
    The number is even.
