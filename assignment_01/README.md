## Task 1: Perform Basic Mathematical Operations

### 📌 Problem Statement
Write a Python program that performs basic mathematical operations on two numbers provided by the user.

### 🧾 Requirements
The program should:

1. Take **two numbers** as input from the user.
2. Perform the following **basic mathematical operations**:
   - Addition
   - Subtraction
   - Multiplication
   - Division
3. Display the result of each operation on the screen.

### 📤 Expected Output
The output should clearly display the result of each mathematical operation performed on the two input numbers.

#### Example Output:
Enter the first number: 5
Enter the second number: 10

Addition: 15
Subtraction: -5
Multiplication: 50
Division: 0.5


## Task 2: Create a Personalized Greeting

### 📌 Problem Statement
Write a Python program that creates a personalized greeting for the user.

### 🧾 Requirements
The program should:

1. Take the user's **first name** and **last name** as input.
2. Concatenate the first name and last name to form the **full name**.
3. Display a personalized greeting message using the full name.

### 📤 Expected Output
The program should output a greeting similar to the following:

Enter your first name: John
Enter your last name: Doe

Hello, John Doe! Welcome to the Python program.
