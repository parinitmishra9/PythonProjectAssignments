## Module 4: Functions & Modules in Python

---

## 📌 Objective
The objective of this assignment is to understand and apply:
- Python functions
- Loops or recursion
- Built-in modules (math module)
- User input and output handling

This assignment contains **two tasks implemented in a single Python program**.

---

## 🧮 Task 1: Calculate Factorial Using a Function

### Problem Statement
- Define a function named `factorial()` that takes a number as an argument.
- Calculate the factorial using a loop or recursion.
- Return the calculated factorial.
- Call the function and display the result.

### Expected Output
```text
Enter a Number: 5
Factorial of 5 is: 120
```

---

## 📐 Task 2: Using the Math Module for Calculations

### Problem Statement
- Ask the user to enter a number as input.
- Use the `math` module to calculate:
  - Square root of the number
  - Natural logarithm (log base *e*) of the number
  - Sine of the number (in radians)
- Display the calculated results.

### Expected Output
```text
Enter a number: 25
Square root: 5.0
Logarithm: 3.2188758248682006
Sine: -0.13235175009777303
```
